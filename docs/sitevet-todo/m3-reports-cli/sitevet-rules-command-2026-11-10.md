# sitevet rules command

List rules as a table, Markdown or JSON. Generate `docs/rules.md`.

## Requirements

- [x] FR-CLI-06 [Must]: `sitevet rules` lists every rule with its ID, category and severity, and whether it needs the browser.
  Acceptance: the list has the same count as the registry.

Spec: `docs/spec/06-build-spec.md`, section 8.

## Result

`sitevet rules [--category c] [--format table|md|json]`: ID, category, severity and whether the rule needs the browser. `docs/rules.md` is generated by `--format md`, and a test fails if it drifts (`UPDATE_DOCS=1` rewrites it). The JSON list has the registry's count, 7 of them browser rules.
